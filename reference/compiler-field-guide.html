三、Source location 约定

Position := { offset, line, column }
SourceLocation := { source, start, end }

offset: 0-based
line:   1-based
column: 0-based
span:   [start, end)  // end-exclusive
  • 半开区间允许直接用 source.slice(start.offset, end.offset) 回取文本。
  • 换行即使被词法阶段跳过，也必须更新 line/column。
  • 父节点 span 覆盖完整子结构；Call 包含左右括号。
  • synthetic target node 没有精确源字符时，应明确继承、标记 generated 或使用 origin，而不是伪造位置。

四、Tokenizer 决策顺序

  1. 到达 EOF：返回 tokens。
  2. 括号：消费一个字符，产生 paren token。
  3. 空白：只消费并更新位置，不产生 token。
  4. 数字或字母：最长匹配连续字符，产生一个 token。
  5. 引号：读到成对结束引号；EOF 前未闭合则词法错误。
  6. 其余字符：UNKNOWN_CHARACTER，位置指向该字符。
token span 与 value 不同

字符串 token 的 span 可以包含两侧引号，而 value 只保存内容。位置来自实际消费，不能用 value.length 倒推。

十一、教学模型边界

  • 该编译器不解析 JavaScript；输出只是一个极小 JavaScript 表达式语句子集。
  • ESTree 风格 location 不表示自定义 AST 完全兼容 ESTree。
  • 位置记录只说明源节点来自哪里；source map 还要记录生成代码 segment 到源位置的映射。
  • 核心没有作用域、符号表、类型检查、优化、模块、宏、错误恢复或增量编译。
  • 扩展语法前先改 grammar、AST schema、diagnostics 与测试矩阵。

十二、对照来源

课程骨架：The Super Tiny Compiler 本地快照。位置模型：ESTree Node objects。生产接口对照：Babel Parser、Traverse 与 Generator。语言复杂度边界：ECMAScript Lexical Grammar。

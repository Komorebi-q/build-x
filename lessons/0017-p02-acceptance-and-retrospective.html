关卡四：明确教学实现与 React 的边界

至少写清以下差异，不需要靠模糊的“功能比较少”概括：

  • 调度器只是演示可让出工作，不复刻 React 的优先级与并发机制。
  • 逐位置 reconciliation 不提供生产级 keyed diff、移动优化和状态身份语义。
  • 宿主 DOM property / event 处理只覆盖声明的最小子集。
  • useState 只演示槽位与队列，不覆盖 batching、eager bailout 或完整 Hooks 系统。
  • 没有 effect、错误边界、hydration、server components、开发模式诊断等能力。

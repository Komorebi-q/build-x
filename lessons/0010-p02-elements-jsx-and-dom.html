P02 · Elements & Host DOM

把 JSX 降低成普通数据

先实现最小的“描述 → DOM”直通路径。你会设计 element 数据结构、规范化文本 children，并用白名单范围处理属性与事件。

60–90 分钟难度：基础产出：element 契约与首次静态渲染

先看转换，不要把 JSX 当模板字符串

输入概念：<button id="save">Save {count}</button>

编译后的形状：
createElement(
  "button",
  { id: "save" },
  "Save ",
  count
)

JSX 语法由编译步骤消除。你的运行时真正接收的是类型、props 和 children；因此先不用 JSX 也能测试核心模型。

1

手工展开三种 JSX

选择一个宿主元素、一个嵌套列表和一个函数组件调用，手工写出它们预期转换后的调用树。再用编译器 playground 核对。

交付：三组“JSX → 调用 → element 数据”转换记录。

定义最小 element 契约

type

字符串表示宿主节点；函数稍后表示函数组件。

props

保存普通属性、事件和统一后的 children。

text element

把字符串和数字包装成与其他节点同形的数据。

children

本课程先约定为扁平数组；更复杂规范化列入边界。

在写实现前先决定 null、布尔值、嵌套数组如何处理。可以暂不支持，但测试必须把选择写清楚，不能让偶然行为变成 API。

2

先写数据形状测试

  1. 无 props 的元素仍得到稳定的 children 容器。
  2. 字符串与数字变成文本描述。
  3. 两个嵌套元素保持顺序。
  4. 对暂不支持的 child 给出明确测试或错误。

交付：element 工厂的输入 / 输出表和至少四个测试。

把 DOM 操作集中在宿主边界

静态版本可以递归创建 DOM，但不要把“遍历 element”与“如何更新 DOM property”揉成一个函数。把宿主操作单独列出：

输入类别最小行为需要测试的风险
文本创建文本节点并设置内容0 不应消失
普通 property设置到 DOM 对象更新与移除必须可区分
事件按约定识别并注册监听器替换 handler 时不能重复触发
children只用于遍历不能作为 DOM property 写入
安全边界

不要为了“像 React”而支持任意 HTML 字符串注入。P02 不需要实现 dangerouslySetInnerHTML；文本应走文本节点路径。

需要你亲自完成的最小垂直切片

  1. 让 element 工厂只生成普通对象，不访问 DOM。
  2. 让宿主工厂根据描述创建元素节点或文本节点。
  3. 让静态 renderer 递归连接父子并挂到容器。
  4. 用一个嵌套两层、含事件和数字文本的页面验证。
提示 1：文本统一的价值

如果文本也有 type 与 props，后续 Fiber 遍历无需在每个阶段判断 primitive。

提示 2：仍卡在事件识别

先定义“哪些 prop key 是事件”的纯函数，再单独测试字符串规则；DOM 注册只是它的消费者。

提示 3：不要继续扩范围

本课只要求首次静态挂载。更新、删除与复用留到 reconciliation 课。
